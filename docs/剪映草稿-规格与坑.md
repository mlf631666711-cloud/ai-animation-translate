# 剪映 11.6 草稿：目录构成、素材箱、四条铁律

> 这份是把我们踩过的坑压缩成可执行的知识。看完这一页，比读三小时源码有用。
> 对应脚本：`tools/jianying/*`。

---

## 1. 一个草稿 = 一整个目录

```
<草稿目录>/
├─ Timelines/
│  ├─ project.json                 ★ 没有它 → 剪映直接报「草稿内容已损坏」
│  └─ <uuid>/                      ← uuid = project.json 的 main_timeline_id
│     ├─ draft_content.json        （真正被加载的内容）
│     ├─ draft_content.json.bak
│     ├─ draft_cover.jpg
│     ├─ template-2.tmp            （与内容同字节）
│     └─ template.json             （明文快照）
├─ draft_content.json              （根镜像，与上面同字节）
├─ template-2.tmp                  （同一个 md5）
├─ draft_meta_info.json            （密文；素材影子清单 + 身份）
├─ draft_virtual_store.json        ★ 素材箱成员树（明文）
├─ draft_cover.jpg                 （明文 JPEG）
├─ draft_settings / draft.extra / timeline_layout.json / key_value.json
├─ crypto_key_store.dat            （每稿不同，但不参与内容解密）
└─ Resources/ adjust_mask/ matting/ … （旁挂，建议整目录克隆）
```

**结论**：不要新建目录手搓。**克隆一个确定能打开的母版**，只替换内容/封面，meta 与素材箱**在母版基础上追加**（老板口径：不动草稿箱里的东西，完整保留）。

## 2. 四条铁律

### ① 内容要 4 处镜像，且逐字节相同

| 路径 |
|---|
| `<草稿>/draft_content.json` |
| `<草稿>/Timelines/<uuid>/draft_content.json` |
| `<草稿>/template-2.tmp` |
| `<草稿>/Timelines/<uuid>/template-2.tmp` |

**加密一次，其余 `copyfile`**。分别加密会因 IV 不同导致 md5 不一致（母版实测四份完全相同）。

### ② 身份三方一致

- 内容 `id` == `Timelines/project.json` 的 `main_timeline_id` == `<uuid>` 目录名
- `draft_meta_info.draft_id` == 根索引里该草稿的 `draft_id`

根索引（**明文**）：`%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft\root_meta_info.json`
一条路径只能一条记录；换名会留 `.staging/.old` 僵尸条目，必须删。

### ③ 素材箱要三层齐备：meta 管列表，树管成员，content 管缩略图

| 层 | 字段 | 作用 | 缺了会怎样 |
|---|---|---|---|
| ① 定义 | `draft_content.materials.videos/audios/images` | 时长 · 尺寸 · 缩略图 · `local_material_id` | 缩略图空白、时长 0 |
| ② 条目 | `draft_meta_info.draft_materials`（`type 0` = 视频/音频/图片 · `6` = 图片 · `8` = 其它） | **素材箱列表就念这一份** | **不显示** |
| ③ 成员 | `draft_virtual_store.draft_virtual_store[type=1]` 的 `child_id` | 「全部」文件夹的成员关系 | **不显示** |

```json
// draft_virtual_store.json
{
  "draft_virtual_store": [
    { "type": 0, "value": [ { "display_name": "", "id": "", ... } ] },                      // 根节点
    { "type": 1, "value": [ { "child_id": "<meta 条目 id>", "parent_id": "" }, ... ] },      // ★ 成员关系
    { "type": 2, "value": [ { "path": "draft_content.json", "is_encrypted": true, ... } ] }
  ],
  "draft_materials": [ ... ]   // 与 meta.draft_materials 同步即可
}
```

**症状**：时间线能正常播放、预览正常，但左上素材箱里**只有音频**（或一个都没有）。

**为什么容易判错**：母版里存在 **9 条素材箱条目在 `content.materials` 里根本没有定义，照样正常显示**
⇒ 列表念的是 `meta`，不是 `content`。`content` 只决定缩略图和时长能不能画出来。

**判据**：`内容素材 ids ⊆ 树 child_ids ⊆ meta 条目 ids`，且 `meta` 条目数 ≥ 母版同组条数。

> 别把判据写成「路径 100% 存在」：母版自带 5 条文件已不存在的历史残留
> （`*-sdr709.png` 合成缓存、`sub_draft_config.json`），这么写会永远假红。
> 正确做法是**与母版对齐**：母版有我们也有、母版缺我们也可以缺。

**剪映的改写行为**：
- 保存时**按内存重建 `meta`**，会丢掉「既不在时间线、又不在它素材库」的条目
  ⇒ 只补 meta 不改内容，下一次保存可能又回去；
- **不清理树**（补进去的成员能活下来）；
- ⇒ 补素材箱的顺序：**关剪映 → 三层一起补 → 回读断言 → 等 30~60s 看 mtime 不变 → 才让人打开**。

### ④ 改文件前先让它别覆写

剪映停在**编辑页**时会定期 autosave（实测 30 秒内），把外部改动整份覆盖掉；
停在**首页**或关闭时不锁目录、也不写回。

**固定顺序**：退到首页/关闭 → 改文件 → 记 `mtime` → 等 30~60s 复核 `mtime` 没变 → 才打开。
**验证法**：改完让剪映自己保存一次，再看哪些字段活下来——活下来的才叫有效位。

## 3. 常见故障对照

| 现象 | 根因 | 修法 |
|---|---|---|
| 「草稿内容已损坏，请联系客服」 | 缺 `Timelines/project.json`（最常见）；镜像 md5 不一致；`new_version`/`platform` 是库默认值（143.0.0 / 空） | 用 `rebuild_draft.py` 重做；版本字段抄母版（11.6 = 189.0.0） |
| 列表里看不到草稿 | 索引没写 / 指向 `.staging` | `swap_draft.py` 写索引；列表不刷新就点进任一旧稿再退出 |
| 换名 `WinError 5 拒绝访问` | 剪映停在编辑页，目录被占 | 退到首页（不用关软件） |
| 素材箱空 / 只有音频 | 见 §2 ③ | `rebuild_draft.py` 已内置：三层合并（meta 条目 + 树成员 + 内容定义），只追加不删 |
| 打开后素材一片红 | 素材路径失效（盘符变了 / 文件移走） | `audit_media.py` 查缺失，改 `path` 后重写 4 处镜像 |
| 卡片时长显示旧的 | 索引里 `tm_duration`/旧条目没更新 | 重跑 `swap_draft.py` |

## 4. 已验证事实（2026-10，剪映 11.6.0.14552）

- 草稿内容是**密文**；加密/解密走 `videoeditor.dll`，需要 `jy_install_dir` 指向安装目录。
- `crypto_key_store.dat` **每稿不同**（141 份 md5 全不一样），但**不参与**内容解密——没有它的草稿也能解开。
- 不用关整个剪映：停在首页时 `shutil.move` 换目录直接成功。
- 不要指望 UIA 操作剪映界面：它是 **Qt Quick**，只暴露 4 个节点，无法按名字/自动化 id 定位。
