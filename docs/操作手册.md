# 从文案到剪映草稿 · 操作手册

> **适用**：翻译线（`语音转动画总项目/翻译/`）任意一个「中文母版 → 英文版」项目。
> **本文是操作手册**：照着敲就能出一条**带英文语音、英文字幕、AI 动画的剪映草稿**。
> 口径与铁律见 `翻译线-总纲.md`；单项目数值见各子项目规格锁。
> **示例全程**：示例项目（3 镜 · 7 段旁白 · 38 条字幕 · 102.148s）。

---

## §0 全流程一图

```
① 文案入库          ② 合成语音        ③ 读音实测        ④ ASR 回环
   _segments.json  →  en/s01..s07.wav → _alias_probe → _asr_check
        │                  │                │              │
        └──────────────────┴────────────────┴──────────────┘
                                   │
                    ⑤ 英化 + 重锚（逐镜，扫 6 类时刻语法）
                                   │
                    ⑥ 逐帧渲染 → 出片（4K / bt709 / LUFS 校验）
                                   │
                    ⑦ 拼条 + 字幕（可选，出 4K 成片）
                                   │
                    ⑧ 剪映草稿（克隆母版目录 → 换名 → 改明文索引）
                                   │
                              打开剪映 ✅
```

**九个动作，六道检查点**。任何一道红，不要往下走。

## §2 第①步 文案入库（分段）

**输入**：项目作者给的英文稿（可能是排版换行，不是语义分段）。
**输出**：`audio/tts_en/_segments.json`。

```json
{
  "_note": "分段真源：只认这一份",
  "_source": "garage_en.md",
  "_matched_by": "母版旁白 ASR + 逐句语义比对",
  "segments": [
    { "id": "S01", "shot": 1, "shot_zh": "赛车爱好者们快看过来…", "text": "Racing fans, look here! ..." },
    { "id": "S02", "shot": 2, "shot_zh": "车库使用一颗乐鑫 ESP32-S3 模组…", "text": "The garage uses an Espressif ..." }
  ]
}
```

**分段口径（可迁移，务必照做）**：

| 情形 | 处理 |
|---|---|
| 以 `.` `!` `?` 结尾 | **独立成段** |
| 以 `,` `:` `—` 结尾 | 视为**排版性断行** ⇒ 与下一行合并 |
| 一个镜次配多段 | 允许（靠 `shot` 字段挂镜） |

**检查点 ①**：`shot` 字段覆盖所有镜次；总词数能对上原稿；段落数与预期一致（本示例 7 段 / 105 词）。

> 屏幕文案是**事实真源**，后面任何环节都不许改它，只改喂给 TTS 的字符。

## §3 第②步 合成语音

```bash
cd 翻译/<项目>-EN/audio/tts_en
python _tts_en.py
```

- 逐段合成，`en/s01.wav` … `en/s0N.wav`；同时拼一条 `joined` 供试听。
- 音色 **`en-US-GuyNeural`**（翻译线共用，**禁混**其他音色）；edge-tts 锁 **7.3.1**（7.2.8 会 403）。

**检查点 ②**：段数 = `_segments.json` 段数；每段时长有值；`joined` 总时长 ≈ 各段之和。

## §4 第③步 读音实测（别凭手感）

```bash
python _alias_probe.py
```

对每个**专名 / 缩写 / 数字单位**列候选写法，逐条测：**时长差 + ASR 回听**，结论落 `_alias_probe.json`。

| 判定 | 规则 |
|---|---|
| 时长差 < 0.1s 且 ASR 还原 | **不需要替身**，原样保留 |
| 读音明显走偏（如 `2.4G` 念成 "two point four gee"，短 0.36s） | 改用 `2.4GHz` |
| 替换实现 | **正则 + 词边界**，否则 `NimBLE` → `NimB L E` 且零报错 |

**检查点 ③**：每条替身都有**实测依据**（时长 + 回听），不许出现"我觉得这样念更顺"。

---

## §5 第④步 ASR 回环

```bash
python _asr_check.py
```

- 用 faster-whisper 把生成的 wav 转回文字，与原文逐条比对。
- **禁止开 `initial_prompt`**（术语密集的 prompt 会把开头整句挤掉 ⇒ 假红）。
- 判法：专名命中数 / 汉字数（英文稿必须 0）/ 时长偏差。

**检查点 ④**：专名全中（本示例 34/34）、汉字 0、偏差 < 0.05s。

---

## §6 第⑤步 英化 + 重锚（逐镜，最危险的一步）

```bash
cd shots/s1
python _patch_en.py      # 改文案 + 改锚点（母版文件只读，产物是 film1_en.html）
```

**必须做**：
1. 复制母版页面为 `film{N}_en.html`，只改五类：文案 / 词轴 / 元素锚点 / 总时长 / 音轨。
2. 用**英文词轴**（`src/en-words/words_shot{N}.json`）重锚，走**分段线性插值**，禁止全局比例。
3. 重锚后跑扫描器，**扫全部 6 类时刻语法**：

| 语法 | 例 |
|---|---|
| `seg(t,A,B)` / `seg(t,A)` | `seg(t,4.34,4.72)` |
| 对象字面量 | `{t:9.44, y:-820}` |
| 区间对象 | `{t0:1.2, t1:3.4}` |
| 简写字段 | `t:9.44` / `t0:1.2` / `t1:3.4` |
| 数组数字对 | `[15.47,19.204444]` |
| 裸比较 | `t > 14.2` |

**检查点 ⑤**：扫描输出逐条人眼过一遍（它是**嫌疑清单**，不是罪证：与母版同值可能是巧合）；确认没有"整条轨还在中文轴"。

## §7 第⑥步 逐帧渲染 → 出片

```bash
# 3D 镜次要先起服务（kit/ 在总项目根）
cd 语音转动画总项目 && python -m http.server 8100 &

cd 翻译/<项目>-EN/shots/s1
node render1en.cjs      # 逐帧 PNG → frames/   4K：viewport 1920×1080 + dpr=2
bash encode1en.sh       # PNG → mp4 + 三道校验
```

**渲染脚本里必须有的自检**（缺一条都可能静默出废片）：

| 自检 | 期望 |
|---|---|
| `devicePixelRatio` | **2**（=4K）；漏了就是 1080p 冒充 4K |
| 舞台缩放 | `1.0000` |
| 画布像素 | 如 1560×2160（按版面） |
| 帧数 | `round(DUR × 30)` |
| `pageerror` + `requestfailed` + `HTTP≥400` | 全 0（3D 跨目录时 module 404 只有后两者抓得住） |

**出片校验**：

| 项 | 通过线 |
|---|---|
| 分辨率 / 帧率 | 3840×2160 · 30fps |
| 色彩 | **bt709 三连**，必须走 `-x264-params`（`-color_trc` 对 mp4 是静默 no-op） |
| 响度 | −16.3 LUFS（本线惯例；**必须真算 BS.1770**，RMS 不能当代理） |
| 文案 | 汉字 **0**，关键英文串全中 |

**检查点 ⑥**：以上全绿 + 抽 3 帧看尺寸 + 人眼看整镜。

## §8 第⑦步 拼条 + 字幕（要 4K 成片时做）

```bash
cd final
python _build_cues_all.py   # 台词 → 字幕条（时间轴对齐语音段）
bash _build_video.sh        # 拼三镜 + 烧字幕 + 响度归一
```

- 字幕规格（项目作者口径）：字号 5 · 思源黑体 CN Heavy · 白字 `#FFFFFF` · 黑描边 `#000000`/0.08 · **删句号** · 逗号后**恰好 1 个空格**。

**检查点 ⑦**：成片时长 = 各镜之和；响度达标；抽帧检查字幕不压脸/不出框。

## §9 第⑧步 生成剪映草稿（核心）

### 9.0 先让人复制一份（这一步必须人做）

在剪映里选中**中文母版** → 右键「复制草稿」→ 改名成英文版的名字（例：`立体车库-英文`）→
然后跟 AI 说：**「我已经把中文版复制了一份，命名为了英文版的了，你在英文版这里操作」**。

- 为什么人来做：剪映的「复制草稿」会把**素材箱里的版面素材**、附件关系一起带过去，脚本新建目录带不走。
- **口径**：动复制出来的素材时，**不要动草稿箱里的东西，完整保留** —— 只往里加本次用到的素材，不删原有的。


> **一句话**：**别手搓 JSON**。剪映 11.6 的一个草稿是**一整个目录**，缺件就报「草稿内容已损坏」。

### 9.1 三步命令

```bash
cd _tools/jy_aoguai

# ① 克隆母版建稿（改脚本顶部的 MASTER / NAME / CONTENT_PLAIN）
python _rebuild_draft.py

# ② 换名 + 改明文索引（旧目录自动留底到 _backup/）
python _swap_draft.py

# ③ 素材与内容审计（防打开后一片红）
python _audit_media.py
python _checklist_broll.py
```

### 9.2 建稿做了什么（`_rebuild_draft.py`）

| 步 | 动作 | 为什么 |
|---|---|---|
| 1 | `copytree(母版 → <名>.new)`，排除 `.backup / matting / textReading / 根大 png` | 结构、旁挂文件、`crypto_key_store.dat` 一次到位 |
| 2 | 内容 `id` ← 母版 `Timelines/project.json` 的 `main_timeline_id` | 时间线不能错挂 |
| 3 | `new_version` / `platform` 抄母版真值（如 `189.0.0` / `11.6.0`） | 库默认 `143.0.0` + 空 platform 是不对的 |
| 4 | 内容**只加密一次**，其余 3 处**逐字节复制** | 母版 4 处镜像 md5 完全相同，不是分别加密 |
| 5 | `draft_meta_info.json` 整份继承母版，只改 `draft_name / fold_path / draft_id / tm_duration` | 身份必须和索引一致 |
| 6 | 封面：明文 JPEG，根与 `Timelines/<uuid>/` 各一份 | — |

### 9.3 换名做了什么（`_swap_draft.py`）

1. 旧目录整包移到 `_backup/<名>-broken-<时间戳>`；
2. `shutil.move` 换名 —— **剪映停在首页就行**（停在编辑页会 `WinError 5`）；
3. 改**明文**索引 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft\root_meta_info.json`：
   删僵尸条目 → 该路径唯一 1 条 → `draft_id` / `draft_json_file` / `draft_cover` 对齐（先自动备份）；
4. 立刻复检 17 项。

### 9.4 剪映交付门禁（缺一条不算交付）

| # | 判据 | 通过线 |
|---|---|---|
| 28 | 结构比对 | 必需文件缺失 = 0，**`Timelines/project.json` 必须在** |
| 29 | 4 处镜像 | 根 content / `Timelines/<uuid>/content` / 两处 `template-2.tmp` **md5 全同** |
| 30 | 身份三方一致 | 内容 `id` == `main_timeline_id` == 目录名；meta `draft_id` == 索引 `draft_id` |
| 31 | 索引干净 | 唯一 1 条 · 无 `.staging/.old` 僵尸 · 是明文 |
| 32 | 素材齐全 | 所有 `path` 存在，缺失 = 0 |

**检查点 ⑧**：28–32 全绿 → **打开剪映**，草稿在「本地草稿」里，能点开、时间线齐全。

## §10 检查点总表（红了别往下走）

| # | 步骤 | 判据 | 红了的典型原因 |
|---|---|---|---|
| ① | 分段 | 段数/镜次覆盖 | 排版换行没合并 |
| ② | TTS | 段数一致 | 音色被换 / 403（版本不对） |
| ③ | 读音 | 有实测依据 | 凭手感改，反而念错 |
| ④ | 回环 | 专名全中 / 汉字 0 | 开了 `initial_prompt` |
| ⑤ | 重锚 | 6 类语法全扫 + 人眼 | 只扫 `seg()` |
| ⑥ | 出片 | 4K / bt709 / LUFS / 汉字 0 | 漏 `?dpr=2`；`-color_trc` 当有效 |
| ⑦ | 拼条 | 时长/规格 | 字幕标点没清理 |
| ⑧ | 草稿 | 28–32 | 缺 `project.json`；镜像不一致；身份不一致；僵尸索引 |

## §11 常见故障 → 对策

| 现象 | 根因 | 对策 |
|---|---|---|
| 剪映：「**草稿内容已损坏**」 | 缺 `Timelines/project.json`（最常见）；镜像/身份不一致 | 重跑 `_rebuild_draft.py`；别手搓 |
| 草稿列表**看不到** | 索引没登记 / 指向 `.staging` | 跑 `_swap_draft.py`；列表不刷新就点进任一旧稿再退出 |
| 换名 `WinError 5 拒绝访问` | 剪映停在**编辑页**（目录被占） | 退到首页即可，**不用退软件** |
| 打开后素材**一片红** | 素材路径失效 | `_audit_media.py` 查缺失，重新指向 |
| 字幕里有**汉字残留** | 母版中文没删干净 | `_checklist_broll.py` 第 24 项，全片扫 0 条 |
| 英文**空格消失**（`Racingfans,`） | 母版逐字 `inline-block` 吃空格 | 空格换 `U+00A0`，字号在**最终 DOM** 上重解 |
| 字号超框、右缘出画 | 按假设字宽算的字号 | 用实测反解（`_probe_width.js`） |
| 成片偏色 | 用 `-color_trc` 打标签 | 改 `-x264-params colorprim/transfer/colormatrix` |
| 响度对不上母版 | 用 RMS 估 LUFS | 真写 BS.1770 / ffmpeg `ebur128` |
| 渲染白屏 | 起播遮罩没隐藏 | 出片前 `display:none` |
| 4K 每帧等 300s | `Promise.race` 当取消器 | 用真取消（`page.close`/AbortSignal） |
| 两镜同时渲染 | 同工程并发 | 同一时刻只跑一个渲染 |

## §13 命令速查（整条复制）

```bash
PROJ="<工作区>/<项目>/"
PY="<本机>/"
NODE="<本机>/"
export NODE_PATH="<本机>/"

# ①②③④ 语音链
cd "$PROJ/audio/tts_en" && "$PY" _tts_en.py && "$PY" _alias_probe.py && "$PY" _asr_check.py

# ⑤⑥ 逐镜
cd "$PROJ/shots/s1" && "$PY" _patch_en.py && "$NODE" render1en.cjs && bash encode1en.sh

# ⑦ 成片
cd "$PROJ/final" && "$PY" _build_cues_all.py && bash _build_video.sh

# ⑧ 剪映草稿
cd "<工作区>/" && "$PY" _rebuild_draft.py && "$PY" _swap_draft.py && "$PY" _audit_media.py
```

> 换项目只改三处：`PROJ`、`_rebuild_draft.py` 顶部的 `MASTER/NAME/CONTENT_PLAIN`、`_swap_draft.py` 顶部的 `NAME`。
